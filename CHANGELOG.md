# Changelog

All notable changes to TokenLens will be documented in this file.

## [0.1.0] - 2026-09-17

### Added
- Initial release of TokenLens — AI Usage & Cost Tracker
- **9 Provider support:** Claude, Cursor, Copilot, Codex, Windsurf, Antigravity, Ollama, DeepSeek, Mistral
- **Local JSONL log parsing** for Claude Code CLI, OpenAI Codex CLI, and Grok CLI
- **Budget Alert System** with configurable monthly budget and notifications at 75%, 90%, 95%, 100%
- **AI ROI Calculator** — calculates hours saved and money equivalent from AI spending
- **Model Leaderboard** — ranks models by cost, tokens, and cost-per-session ratio
- **Trend Chart** — hourly/daily usage visualization using uPlot
- **Share Card** — export PNG summary of monthly stats
- **Status bar** with progress bars, budget-aware color coding, and provider selection
- **PricingService** with catalog of Claude, Codex/GPT, Grok, and DeepSeek model prices
- **ExchangeRateService** for multi-currency display
- **Auto-refresh** with configurable intervals (1m, 2m, 5m, 15m, 30m)
- **Local source auto-detection** for JSONL log files
- 100% local — no telemetry, no data leaves your machine
